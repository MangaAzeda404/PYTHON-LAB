    A BASE POR TRÁS DOS EXEMPLOS

    Entenda os fundamentos.

    01

    Guardar informações

    Variáveis associam nomes a valores. Em Python, usamos = para atribuir um valor e precisamos defini-lo antes de lê-lo.

    nome = "João"       # str
quantidade = 7      # int
peso = 2.5          # float
pode_entrar = True  # bool

    Strings usam aspas simples ou duplas. let e const não declaram variáveis em Python.

    02

    Receber e mostrar

    input() recebe uma entrada como texto. int() e float() convertem entradas válidas em números.

    idade = int(input("Idade: "))
print(f"Você tem {idade} anos.")

    print() exibe informações. A f-string coloca os valores entre chaves na mensagem.

    03

    Calcular e decidir

    Operadores fazem cálculos e comparações. if e else escolhem um bloco a partir de uma condição.

    if total_pessoas <= 100:
    print("Todos podem entrar.")
else:
    print("O grupo excede a capacidade.")

    A indentação faz parte da sintaxe. == compara; = atribui.
