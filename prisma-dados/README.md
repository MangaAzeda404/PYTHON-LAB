# PRISMA DADOS — Estúdio de pesquisa

Projeto diferente dos cadernos anteriores: um estúdio para transformar dados em uma apresentação editável de cinco slides.

Site: https://mangaazeda404.github.io/PYTHON-LAB/prisma-dados/

Edite tema, público, notas, conclusão e paleta. Calcule média, mediana e moda, navegue nos slides e use o modo apresentação (Esc sai; setas navegam). Salve em PDF pela impressão do navegador. Copie um pedido específico para usar em uma IA externa. Não há chamada de IA nem conexão ao Canva.

O exemplo inicial usa 6, 7, 1, 7, 2, 10, 6 e 6: média 5,625, mediana 6 e moda 6. A outra questão (7,4/7/8) não representa este conjunto. Sem repetições, o conjunto é amodal; empates mostram todas as modas.

As onze questões recentes orientam o produto: estatística, pedido com público e formato, revisão humana, contraste, preparação de dados, distribuição, identidade visual, prompts específicos e compartilhamento para comentários. O arquivo questions.json guarda o gabarito de referência, incluindo as ressalvas sobre alternativas ambíguas.

Abra index.html no navegador. Os dados ficam apenas na página, sem envio ou persistência. A tabela mostra as frequências exatas; não há histograma inventado. Os slides refletem textos e conclusões fornecidos pelo usuário e precisam de revisão antes da entrega.
